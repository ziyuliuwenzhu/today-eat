# 今天吃什么

一个同时适配手机和电脑浏览器的随机抽签小工具，可用于抽取美食和饭搭子。

## 功能

- 无限次抽取“吃什么”或“找谁吃”
- 菜单与饭搭子分别管理
- 支持批量导入、图片文字识别导入
- 支持自定义标签，一个项目可设置多个标签
- 支持新增、重命名和删除标签
- 支持按标签筛选后抽签
- 连续抽取三次后给出选择建议
- 支持重置当前一轮抽签
- 清空菜单或饭搭子后支持撤回恢复
- 手机端与电脑端自适应显示

## 文件说明

- `index.html`：完整应用，也是 GitHub Pages 的默认首页。HTML、CSS 和 JavaScript 均已包含在这个文件中，无需安装依赖或执行构建命令。
- `today-eat.html`：原始文件的兼容备份，功能与 `index.html` 相同。
- `README.md`：项目说明和维护指南。

## 本地使用

下载项目后，直接双击 `index.html`，即可用浏览器打开。也可以在编辑器中修改，然后刷新浏览器查看效果。

## 上传到 GitHub

1. 打开仓库的文件上传页面。
2. 将 `index.html`、`today-eat.html` 和 `README.md` 一起拖入页面。
3. 在页面底部填写提交说明，例如“上传完整项目文件”。
4. 点击 **Commit changes**。

如果 GitHub Pages 已设置为从 `main` 分支的根目录发布，上传 `index.html` 后，项目可以直接通过仓库的 GitHub Pages 根网址访问。

## 在其他设备维护

可以在 GitHub 仓库中直接编辑 `index.html`，也可以下载整个仓库后用任意代码编辑器修改。修改完成后，把更新后的文件重新上传并覆盖仓库中的同名文件即可。

建议以后以 `index.html` 为主要维护文件。若继续保留 `today-eat.html`，发布新版本时请同步覆盖它，避免两个文件的功能不一致。

## 数据存储说明

菜单、饭搭子、标签等用户数据保存在当前浏览器的 `localStorage` 中，存储键为 `today-eat-v3`。源码已经内置当前默认菜单和饭搭子，新设备第一次打开时会自动加载。之后在各设备上新增或修改的数据不会自动同步到其他浏览器或设备。

请不要在浏览器中清除该站点的数据，否则本地录入内容可能丢失。
